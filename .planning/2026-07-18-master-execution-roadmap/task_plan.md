# Master Execution Roadmap Governance

## Goal

Create and enforce one complete project execution roadmap so specialized plans
cannot silently change the overall sequence.

## Checklist

- [x] Reconcile the rules, current index, long-term roadmap, Qlib plan, and live
  LightGBM migration state.
- [x] Define the complete P0-P9 sequence, dependencies, gates, fallbacks, stop
  rules, and completion criteria.
- [x] Make the master plan required reading and mark older plans as technical
  references rather than competing execution authorities.
- [x] Verify cross-document references and record the governance change.

## Constraints

- Registry and research protocol remain authoritative for formal values.
- Specialized plans can expand only the currently active master-plan stage.
- No training, backtest, candidate promotion, or lifecycle transition is part
  of this documentation task.
