## 推荐参数

### 当前主推荐

`max095 + target0.008 + hold0.15 + rebalance_band0.30`

理由：

- base 不一定是最高，但足够强
- lag1 和 cost2x 后仍然稳
- 50w/100w 同参数表现稳定
- 换手比 `hold0.08` 明显低
- 更适合实盘长期跟踪

### 激进备选

`max095 + target0.008 + hold0.08 + rebalance_band0.20 或 0.25`

理由：

- base 年化和 Sharpe 最高
- 适合观察，但暂不建议作为第一实盘口径
- 换手和成本更高，对真实成交更敏感

### 保守备选

`max090 + target0.005 + hold0.12 + rebalance_band0.30`

理由：

- 最低年化较高
- 最大回撤略低
- 但换手仍不低，且整体 Sharpe 不如主推荐

## 当前判断

本轮全排列后，建议将正式候选参数从原来的：

`max095 + target0.006 + hold0.10 + band0.20`

升级为：

`max095 + target0.008 + hold0.15 + band0.30`

旧参数更像一个稳健基线，新参数在收益、稳定性和换手之间更均衡。
